# Security Policy

## Supported versions

Security fixes are provided for the latest stable QuotaHush release. Please
update before reporting an issue that may already have been resolved.

## Report a vulnerability privately

Do not open a public issue for a vulnerability or include credentials, tokens,
`.var.env` contents, or unredacted logs in a report. Use GitHub's
[private vulnerability reporting](https://github.com/Wenress/QuotaHush/security/advisories/new)
instead.

Include the affected version and platform, the impact, reproduction steps, and
any suggested mitigation. You can expect an initial acknowledgement within
seven days. Fix and disclosure timing depends on severity and complexity.

## Release integrity

Official artifacts are published only through
[GitHub Releases](https://github.com/Wenress/QuotaHush/releases). Each release
includes SHA-256 checksums and GitHub artifact attestations. See
[Verifying releases](VERIFYING_RELEASES.md) before running an unsigned Windows
installer.
