# Code of Conduct

QuotaHush aims to be a welcoming, practical, and harassment-free project.

Participants should be respectful, assume good faith, accept constructive
feedback, and focus discussion on improving the project. Harassment,
discrimination, threats, personal attacks, deliberate disruption, and the
publication of another person's private information are not acceptable.

Maintainers may edit or remove contributions and temporarily or permanently
restrict participation when conduct is inappropriate. Enforcement decisions
should be proportionate, documented privately, and protect the people involved.

If you experience or witness unacceptable behavior, contact the repository
owner through their GitHub profile or use GitHub's abuse-reporting tools. Do not
open a public issue containing sensitive personal information.
